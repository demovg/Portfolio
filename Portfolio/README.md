# Abrham Habtamu — Developer Portfolio

A personal portfolio website built with React, TanStack Start, and Tailwind CSS. It showcases my projects, skills, certificates, and provides a way to get in touch.

## Live Demo

> Coming soon — deploying on Vercel

## Features

- Responsive design with dark/light mode toggle
- Hero section with CV download
- About section with personal bio
- Skills & tech stack display
- Project showcase with live demo and source code links
- Certificates section with viewable credentials
- Contact form via mailto
- Fixed side social links (GitHub, LinkedIn, Telegram, Email)

## Tech Stack

- **Framework** — React 19 + TanStack Start + TanStack Router
- **Styling** — Tailwind CSS v4 + custom CSS utilities
- **UI** — shadcn/ui (Radix UI primitives)
- **Icons** — Lucide React
- **Build Tool** — Vite
- **Language** — TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
